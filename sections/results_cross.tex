\label{sec:r-cross}
% Owner: A for cross-network synthesis;
% B supplies CIT results; C supplies H2/H3 results.

\Cref{tab:cross} summarizes the available evidence
across the three networks.
H2 and H3 have now been evaluated for PS and CM
using timestamp-shuffled P1 null models.
Other PS/CM experiments remain pending.
A complete ranking of network types by temporal
sensitivity is therefore not yet established.

For H2, both PS and CM exhibit higher pooled
burstiness than P1, but lower pooled memory.
For H3, link persistence depends on network type
and temporal aggregation scale.
The split H4 verdict avoids treating densification,
diameter shrinkage, descriptive fit and predictive
superiority as interchangeable claims.

The H2 results support stronger-than-null
burstiness in both PS and CM, but do not support
stronger-than-null adjacent-gap memory.

For H3, PS exhibits lower link overlap than P1
at all tested window sizes.
CM shows higher overlap at shorter windows,
but the contrast reverses at 14 days.
Therefore, temporal link persistence is not
consistent across network types or time scales.

These comparisons demonstrate that temporal
organization affects network measurements,
although the magnitude and direction depend
on event definitions, network type and
aggregation scale.
